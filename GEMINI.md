# Readers Hub Development & Interaction Rules

## Teaching & Learning Protocol
Whenever solving a problem, adding a feature, or fixing a bug:
1. **Explain What Was Done**: Detail the exact code changes and the engineering reason behind them so the user understands the architecture and root causes.
2. **Explain Tools & Techniques Used**: Clearly mention the tools, commands, and methodologies used during the process (e.g., Open Library REST APIs, React lifecycle hooks, TypeScript validation with Vite, Python diagnostic scripts, Tailwind CSS design tokens, Git version control).
3. **Foster Continuous Learning**: Highlight useful tips, best practices, and new concepts introduced during the task so the user can build their software engineering intuition over time.
4. **Code Quality**: Always ensure zero-error builds (`tsc -b && vite build`) and follow clean, production-grade coding standards.
